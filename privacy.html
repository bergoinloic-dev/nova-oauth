Privacy Policy

NOVA VORTEX YouTube — last updated: 30 September 2026

1. Who we are

NOVA VORTEX YouTube ("the application") is a personal, self-hosted tool operated by Loïc Bergoin ("the operator") to manage his own YouTube channels. It runs only on the operator's own computer. It is not a public service: its only user is the operator, signing in with the Google accounts that own his channels.

2. Google user data the application accesses

The application uses Google OAuth and the YouTube API Services. With the operator's consent, it requests these permissions (scopes):

  • https://www.googleapis.com/auth/youtube.force-ssl — to upload videos to the operator's own channel, update their title, description, privacy status and scheduled publication date, set their thumbnail and captions, and read the identity of the connected channel.
  • https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/yt-analytics.readonly — to read, without modifying anything, the list and statistics (views, watch time and similar metrics) of the operator's own channels.

The data accessed through these permissions is: the channel identifier and title; the identifiers, status, metadata and scheduled publication dates of the videos the application uploads or reads; and the aggregated statistics of the operator's own channels. The application does not access Gmail, contacts, files or any other Google service, and it does not access any private data of other YouTube users.

Public YouTube data (no sign-in)

Separately, for topic research, the application uses the YouTube Data API with an API key (no Google sign-in) to search public videos: public titles, channel names, durations and view counts. Names of people, places or events taken from public video titles may be used as search queries with a web search provider (Tavily) to check that a topic is documented by independent sources.

3. How the data is used

The data is used only to publish and manage the operator's own videos, to show the operator the performance of his own channels, and to research topics for future videos. It is not used for advertising, it is not sold, and it is not used to build profiles of anyone.

4. Storage and security

  • OAuth refresh tokens are stored only on the operator's computer, in local environment (.env) files that are never published or shared. Short-lived access tokens are kept in memory only and are never written to disk.
  • Channel, video, statistics and research data retrieved from YouTube is stored only in local files and databases on the operator's computer. The application has no server and no cloud database of its own.

5. Sharing

Data obtained with the operator's Google sign-in (section 2: the operator's channels, videos and statistics) is not shared with, transferred to, or sold to any third party; it is exchanged only with Google's own servers. The only YouTube-derived information sent elsewhere is the search terms described under "Public YouTube data", sent to the web search provider.

6. Retention and deletion

  • OAuth tokens are kept until the operator revokes the application's access or deletes them from the local files.
  • Records of uploaded videos, statistics history and research results are kept in local files with no automatic expiry, for as long as the operator uses the application. They are removed by deleting those local files.
  • Videos uploaded to YouTube stay on YouTube until the channel owner deletes them in YouTube.
  • Access can be revoked at any time at https://myaccount.google.com/permissions. Once access is revoked, the application can no longer access the account.

7. YouTube and Google policies

The application uses the YouTube API Services. By using it, you also agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes

If this policy changes, the updated version is published on this page with a new date.
